## 3. 主動式 ETF 卡片：持股明細從「前5大一行字」改成「卡片內完整表格」

使用者發現卡片上 `前5大持股：2330 台積電 10.5%、...` 那行其實資料本身就有全部
持股（PCF 快照的 `weight` 欄不是只存前 5 大），問「能不能看全部」。

**中間換過一次做法**（先做方案 1 再依使用者要求改方案 2，兩個都測過綠燈）：
- **方案 1（已改掉）**：`st.expander` + `st.dataframe` 放在卡片**外面**（因為卡片
  本身是拼出來的 HTML 字串，`st.dataframe` 是真正的 Streamlit 元件，塞不進
  `unsafe_allow_html` 的字串裡）。使用者問「放卡片裡面展開會有問題嗎」，答案是
  技術上可以，但要改用純 HTML `<details>` + 手刻表格，失去 `st.dataframe` 內建
  的捲動高度控制，要自己補 CSS。
- **方案 2（現行）**：卡片內用 `.thc-details`（跟其他卡片「明細」同一套視覺）
  展開一個純 HTML `<table>`，外面包一層 `.ae-hold-wrap`（`max-height:340px;
  overflow-y:auto`，表頭 `position:sticky`）做出「先看約10列、往下捲看其餘全部」
  的效果。

**改動的函式**：
- `_holdings_df(code, date)`：讀 PCF 快照全部持股，依 `weight` 降冪排序（原本
  `_top_holdings()` 只砍 `.head(5)` 回一行字，現在回整份 DataFrame）。
- `_holdings_table_html(df)`：新增，把排序好的 DataFrame 拼成
  `<details><summary>持股明細（N 檔，依權重排序）</summary><table>...</table></details>`。
- `_ae_card(...)`：`top_line` 參數整個拿掉（原本只有這個用途，現在用不到了），
  新增 `holdings_html` 參數，插入卡片內容（買賣兩欄之後、`meta_line` 之前）。
- CSS 新增 `.ae-hold-wrap` / `.ae-hold-table`（緊接在 `.ae-stack` 那組樣式後面）。
