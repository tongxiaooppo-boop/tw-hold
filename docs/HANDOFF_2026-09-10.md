## 3. 撤回版旗標的設計（要復活就照這個）

- **4 個表面**，共用一個 `_active_flags()` load + `_active_chip`/`_active_evidence`/`_active_legend` helper：
  1. 長波段候選池卡 `_swing_b_html`：進支持/反對欄 + chip
  2. 短線頁卡 `_short_b_html`：chip
  3. 個股查詢 `_stock_page`：表頭 chip + 一句
  4. 多軌體檢：`checklist.short_checks(d, active_etf=)` / `swing_checks(d, active_etf=)` 加 kw，「籌碼」組加一列（買超→✅、賣超→⚠️命中、無動作→無資料、來源過期/None→整列不出現）
- **`data/derived/active_etf_flags.json` schema**：
  ```
  {"_meta": {"source", "anchor_date", "market_date", "fetched_at",
             "total_etfs", "synced_etfs"/"stale_etfs", "schema_ok"},
   "flags": {"<code>": {"name","industry","net_shares","net_amount","issuer_count",
                        "consensus","consensus_strong","buyers","sellers","kind"}}}
  ```
  `kind` ∈ `consensus_buy|buy|sell|consensus_sell|neutral`。
- **降級**：`schema_ok` false 或 `anchor_date` 落後 > 4 天 → `_active_flags()` 回 `{}` → App 完全不顯示旗標（多軌那列顯「無資料」）。
- **commit 進 repo**（比照 `swing_list.json`），App 只讀本地檔、零 runtime。
