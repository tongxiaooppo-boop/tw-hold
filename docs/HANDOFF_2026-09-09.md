  換行墊在下方、自動加「現值」「門檻」標籤
- CSS 在 `_CSS` 的 `.thc-cl*` 區塊（`streamlit_app.py` L188 附近）
- `_render_checks`（L731）內：`st.dataframe` loop → 每個「組」組一段 HTML 字串
- `test_app_smoke.py` L49：smoke 從找 `at.dataframe` 改成找 `thc-cl-row` markdown
