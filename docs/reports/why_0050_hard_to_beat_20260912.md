# 為什麼三條線都打不過 0050——大盤集中在少數超級贏家

- 產出：2026-09-12
- 背景：實驗 B'（價值線）、實驗 E（長波段）、tw-swing 111 條買得到全掃，三次獨立回測
  都指向同一個結論——**tw-hold 的分散式選股規則，年化跟回撤都打不過 0050**。這份筆記
  量化「為什麼」，供之後說服別人「不如買 0050 就好、不用自己選股」時引用。

## 數字

2016-01 → 2026-09（跟三條線回測同一段期間），還原（含息）收盤累積報酬：

| | 累積報酬 |
| :-- | --: |
| **0050** | +887% |
| 台積電 2330 | **+2,160%** |
| 聯發科 2454 | **+2,783%** |
| 台達電 2308 | **+1,432%** |

這三檔的漲幅**都遠超過 0050 本身**。台積電長期在 0050 裡的權重約 35–45%，光這一檔
粗算貢獻就接近 0050 全部漲幅的 8–9 成，聯發科、台達電再疊加上去——**0050 這段期間
的報酬幾乎是這三檔半導體/科技巨頭撐出來的，指數裡其他幾百檔平均起來遠遠沒有這麼猛**。

## 意涵

任何分散在 100+ 檔的規則型選股策略（不管是價值面 F-Score/Magic Formula、還是
CANSLIM+Minervini 這種趨勢面），本質上都是在**對抗一個高度集中押注少數贏家的指數**。
選股邏輯就算完全正確、篩出來的公司體質也確實比較好，只要沒有重壓到台積電/聯發科/
台達電這個量級的少數幾檔，數學上就贏不了 0050——這不是策略設計的缺陷，是這段期間
（2016–2026 半導體超級循環）大盤本身的結構性特徵。

**換句話說**：這段期間如果目標是「贏過大盤」，分散式選股的天花板本來就比重押式的
市值加權指數低。想贏 0050，得靠重壓、不是分散；但重壓也代表承擔對應的集中度風險
（萬一押錯或台積電這類巨頭見頂，跌起來也是同一批人先倒）。

  實驗 B（價值/定存 2026-09-07）、實驗 B'（價值 2026-09-12）、實驗 E（長波段
  2026-09-12）三次獨立回測方向一致，見各自報告的生存者偏差段落。
- 這份筆記量化的是「為什麼」，可以直接拿給別人看：**如果目標只是資產成長、不是
  研究樂趣，這段期間買 0050（或乾脆更集中的台積電/聯發科）比自己選股規則化的
  分散組合更有效率**——tw-hold 存在的價值在於「省你自己篩選 + 給判斷依據」，
  不是宣稱能贏大盤。
