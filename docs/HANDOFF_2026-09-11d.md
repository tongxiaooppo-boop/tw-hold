### ✅ 修掉圖示重疊 bug（併在 `fef0004`）

使用者翻頁時發現「複製給 AI」展開箭頭跟一串看起來像 `_arrow_right` 的亂碼

var(--thc-sans)}` 把全站 `<span>` 都蓋成 Manrope 字體，但 Streamlit 的展開

字體被蓋掉後圖示就顯示成沒渲染的原始文字。**修法**：選擇器排除這個
testid（`.stApp span:not([data-testid="stIconMaterial"])`），跟這輪表頭
調整無關，是撿到的舊 bug（不是這輪改動造成的）。

## 1.5 🆕 下一場的主要工作：長波段候選池回測（2026-09-11 深夜裁決）

使用者問「長波段那條國際策略（CANSLIM + Minervini）可用嗎？**不求賺多少，但不要賠很大**」。
查完的答案是：**這條線唯一測過的是產能，不是報酬，更不是回撤。**

`research/candidate_pool_survey.py`（實驗 D）docstring 第一行寫著「**這不是回測，是可行性
普查**」，判準是「中位數 1–5 檔、空白週 < 30% = 可行」。它量到中位數 2 檔、空白週 34% ——
**沒有報酬、沒有勝率、沒有回撤、沒有樣本外**。所以 app 上那句「沒有回測支撐」是準確的，
而使用者真正在意的那一欄（會賠多少）**目前是零資訊**。

### 關鍵發現：它其實規格齊全，只是沒人接起來跑過

PRD §5.2／§5.3 已經定義完整三件：

| | 規格 |
| :-- | :-- |
| 進場 | 候選池六條件全過（CANSLIM 基本面 ∩ 月營收 ∩ 法人 ∩ 趨勢模板 8/8） |
| 停損 | `risk_stop` = max(50MA, 20 週前低, 現價 − 2×ATR14) |
| 可買上限 | `max_buy` = 停損 ÷ (1 − 10%) |
| 出場 | §5.2.3 失效條件：收盤跌破 50MA／趨勢模板 < 5/8／月營收 YoY 轉負／季 EPS YoY 轉負 |

app 標「v3.1 不追蹤持倉」只是說**產品不幫你盯**，不是規格沒定義。
**測它不需要設計任何新東西**，資料 bundle 全都有。

### 回測規格

- **進場**：候選池全過（週頻；`candidate_pool_survey.py` 已能逐週重建 550 週的名單）
- **口徑**：**次日開盤 + `limit_at_close` 兩份**（🔴 一開始就上誠實口徑，不要先產一個
  訊號日收盤的漂亮數字——tw-swing 在這件事上摔過，見該專案 STATUS 09-10）
- **停損 / 出場**：照上表，不要自己另外發明
- **對照**：0050 含息同期
- **產出重點**：**最大回撤**（這是使用者真正在問的）、年化、分年、
  **分市況（多頭/震盪/空頭）**、樣本外切 2022
- 🔴 **生存者偏差標成上界**（universe = 今天的前 514 大回掃 2016，腳本自己標過）

### 先驗（是推論不是數據，跑完以數據為準）

不利：① 六個狀態條件的交集，tw-swing 台帳對這形狀的判語是「市場 beta」
（V1 MACD 29,672 筆回撤 −42%、V3 ADX 28,962 筆回撤 −44%）；② Minervini 8/8 要求貼近
52 週高 + 站上所有均線＝**追高進場**，regime 反轉時回撤深；③ 生存者偏差讓結果偏樂觀。

有利：① **空頭週 45% 是空白的**（多頭 25%／震盪 40%）——空頭會自動減少進場，
這對「不賠很大」是實質幫助，跟天天有訊號的 MACD/ADX 不同；② 品質門檻
（ROE > 15%、F-Score ≥ 6、EPS YoY > 25%）確實在濾地雷。

### 結論的用法

**跑完之前：當「觀察清單」可以，當「下單依據」不行。** 「不賠很大」是風險宣稱，
風險宣稱必須有數字才成立。三種結局都可接受，**第三種一樣有價值**：
① 有超額 → disclaimer 重寫、升級成有數字的候選池；② 不輸不贏 → 頁面改講
「≈ 大盤，價值在省你自己篩」；③ 輸 0050 → 砍掉或降成純瀏覽工具，
**使用者從此不必再對一條沒證據的線抱期待**。
