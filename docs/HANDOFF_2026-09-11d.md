## 1. 這一輪做了什麼（2026-09-11 晚上，接續 `HANDOFF_2026-09-11c.md`）

使用者覺得每一頁表頭「投資警語、功能警語、建立時間、一堆亂七八糟資訊」太擠，
要求精簡；順便聊到「雷達」這個 app 名稱可以做點視覺巧思，最後落地成分頁選單
上的一個小紅色雷達鎖定徽章。過程中翻頁時使用者順手抓到一個真的 CSS bug。

### ✅ 簡化 7 個分頁表頭（`8165d78`）

價值/定存/長波段/短線/個股查詢/多軌體檢/主動式ETF 全部套同一條規則：
**表頭只留「資料日期／建立(重算)時間＋投資警語」**，功能說明文字（CANSLIM
講解、「不打分不給買賣建議」這類方法論句子）、功能專屬警語（🔴
`SWING_DISCLAIMER`／🔴🔴 `SHORT_DISCLAIMER`）、g2_note、tw-swing 原文附帶的
disclaimer 清單全部搬到頁尾。**例外**：資料異常的即時警報（CI 沒跑、
`schema_ok=False`、快照過期、清單過期）**留在原位沒搬**——這種是「現在看到
的數字可能有問題」的即時提示，搬到頁尾等於看完整頁才發現資料是壞的，判斷
上不該跟方法論說明一起被摺疊掉。

多軌體檢頁原本表頭完全沒有投資警語（只有各軌內嵌的功能警語），這輪順手在
頁尾補了一個通用 `_disclaimer()`，讓 7 頁都有。

### ✅ 修掉圖示重疊 bug（併在 `fef0004`）

使用者翻頁時發現「複製給 AI」展開箭頭跟一串看起來像 `_arrow_right` 的亂碼
文字疊在一起，桌機手機都中。**根因**：`_CSS` 裡 `.stApp span{font-family:
var(--thc-sans)}` 把全站 `<span>` 都蓋成 Manrope 字體，但 Streamlit 的展開
箭頭圖示也是 `<span data-testid="stIconMaterial">`，靠 Google Material
Symbols 字體的 ligature 把文字（如 `keyboard_arrow_right`）顯示成圖示——
字體被蓋掉後圖示就顯示成沒渲染的原始文字。**修法**：選擇器排除這個
testid（`.stApp span:not([data-testid="stIconMaterial"])`），跟這輪表頭
調整無關，是撿到的舊 bug（不是這輪改動造成的）。

### ✅ 雷達鎖定徽章（`fef0004` + `f132f12`）

聊「雷達」這個 app 名字可以怎麼玩視覺，中間用 Claude Design 畫了一輪
線框稿定方向（連結見下），最後拍板：**不做大面板，維持原本 `st.radio`
分頁列，只在目前選中的分頁後面疊一個很小的紅色雷達徽章**（同心圈＋掃描
扇形＋中心點）。演進過程：

1. 最早想法是 8 角雷達整個取代/新增導覽面板（太佔版面，使用者喊停）
2. 縮小成「選中的才鎖定」，先試過角括號準星、圓環兩種鎖定框
3. 使用者要求「選項不要再有選擇圈/框」→ 改成準星懸浮／四邊刻度線疊字
4. 使用者丟一張深色復古雷達螢幕參考圖，講清楚「掃描中心就是選項」→
   最終定案：**雷達badge直接疊在選中文字後面，體積跟文字差不多大，不佔
   額外版面**
5. 顏色從灰藍改成紅色——沿用 app 既有 `--thc-up`（台股「紅漲」）同一色號，
   不是另外發明的顏色

線框稿在這裡（Claude Design 畫的，非最終成品，僅供設計過程參考）：
<https://claude.ai/code/artifact/213cee85-16f2-4e7c-a5e0-85710d0d7d08>

**實作**（`app/streamlit_app.py` `main()`）：純 CSS，讀了 Streamlit 前端
原始碼確認 `st.radio` 每個選項渲染成 `<label data-testid="stRadioOption">`，
依 `NAV` list 順序排列——用 `NAV.index(nav)+1` 算出 `:nth-of-type(N)`
點準目前選中的那個，塞進一段每次 rerun 都重新產生的 `<style>` 區塊，不用
去猜 BaseWeb/react-aria 內部 `checked` 狀態怎麼反映在 DOM class 上。掃描
扇形角度不是每頁指同一個方向，改成 8 方位環算（`NAV.index(nav)*45-22.5`
度）：價值=正上方(0°)、定存45°、長波段正右(90°)、短線135°、個股查詢正下
(180°)、多軌體檢225°、主動式ETF正左(270°)，**幫未來第 8 個「美股焦點」
留了 315°（左上）**——但 `NAV` 目前還是只有 7 項，這個角度只是預留，
美股還沒真的加進 nav。順便也把 `st.radio` 選項前面原生的圓圈勾選標藏掉了
（`:has()` 抓「跟 `stMarkdownContainer` 同排的第一個 div」，不猜 class 名）。

**注意**：這幾輪 CSS 改動我這邊沒有瀏覽器可以截圖驗證，只跑過語法檢查 +
`pytest -q` + Streamlit `AppTest`（無瀏覽器，確認腳本不噴錯、nav 邏輯對），
**下一輪開工前務必自己在瀏覽器裡看一次**：雷達徽章位置/大小順不順眼、
扇形角度轉對了沒、圓圈是不是真的消失了。

### ✅ 美股追蹤資料設計定案（沒動程式，只是討論+記憶）

使用者問「那斯達克要 24 小時交易，收盤價還有意義嗎」。結論：**24 小時交易

[[tw-hold-us-stock-tracking-design]]，**這條線還沒開始接資料**，`NAV`
list 也還沒加第 8 項，純粹是先把設計決策記下來，之後要動工時不用重新
猶豫要不要做即時。
