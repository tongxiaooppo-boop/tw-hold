> 2026-10-06。**原則：事件名稱、欄位、基準價一律用官方表的原詞與原值，不自建名詞、不從價格跳動猜事件。**
> 資料來源：TWSE／TPEx 官方事件表（逐一實抓確認過欄位與值）；Gemini、GPT 兩份清單當「待核對的線索」，逐項對官方表與我們的資料驗證，**不直接採用**（見第 3 節）。

**官方沒有獨立的「現金增資」事件。** 現金增資是「除權」裡的欄位（TPEx：現金增資股數、認購價…；TWSE：預告表 `TWT48U` 的無償配股率、現金增資配股率、現金增資認購價）。員工紅利轉增資、盈餘轉增資、資本公積轉增資在官方表也都只是「除權」（每仟股無償配股）。所以我們不另立「現金增資」「轉增資」這類事件名稱。

### `corp_actions` 欄位對照（官方用語 ↔ 欄名）
| 欄名 | 官方用語 | 備註 |
| :-- | :-- | :-- |
| `event` | 除息／除權／除權息／減資／變更股票面額／分割 | 官方原詞（TWSE 的 息／權／權息 統一寫成 TPEx 的全稱） |
| `reason` | 減資原因 | 官方原詞：退還股款、彌補虧損、現金減資；FinMind 來源保留其原文（Cash refund、Making up losses） |
| `prev_close` | 除權息前收盤價／停止買賣前收盤價格 | |
| `ref_price` | 除權息參考價／恢復買賣參考價（減資併現增＝除權參考價） | 還原因子＝ref_price ÷ prev_close |
| `open_base` | 開盤競價基準（TPEx：開始交易基準價） | 含現金增資時與 `ref_price` **不同**（見下） |
| `div_ref` | 減除股利參考價 | 只有除權息表有 |
| `limit_up`／`limit_down` | 漲停價格／跌停價格 | |
| `type` | （舊內部代碼 ex_div、ex_rights、ex_both、cap_reduction、par_change、split） | 與 `event` 一一對應，**只為相容保留**，新程式用 `event` |

**除權息參考價 vs 減除股利參考價（現金增資的差別）：** 2614（2026-10-06）前收 19.10，除權息參考價 16.13（含現增稀釋），減除股利參考價 17.31，開盤競價基準 17.30。官方規定含現金增資時，開盤基準取最接近「減除股利參考價」的檔位價，**不是**除權息參考價；漲停也是從減除股利參考價算起。我們的還原因子用除權息參考價（官方的「除權息參考價」，與 tw-stock-data 一致）；開盤競價基準另存一欄，不混用。

### 官方對這張表的驗證（我們的資料實測）
- 事件日有實價的 **18,027 筆，收盤全部落在官方漲停價與跌停價之內（0 筆例外）**。
- 官方行情自己在「參考價被重設」的日子標記（上市漲跌欄 `X`；上櫃漲跌欄直接寫除息／除權／除權息）：全史相鄰交易日的標記日 16,967 個，事件表對上 16,941 個，其餘 26 個全是轉板首日。
