## 2. 發現的 bug（根因已確認，修法已知，但還沒驗證跑通）

**症狀**：使用者回報「裡面沒數據」——合併頁面裡「買得到帳本」這個分頁，
「長波段候選池」表格、「價值因子指數」表格、「tw-swing 精選規則」的規則
清單（accordion）全部是空的，只有最上面的總覽圖表跟最下面的附錄表格有
內容。**本機開離線檔跟開 claude.ai 網址兩邊都一樣壞**（已排除是本機檔案
少了 HTML skeleton 的問題——那個懷疑後來證明是錯的，claude.ai 那邊有正確
包 skeleton 也一樣壞，代表問題出在程式邏輯本身，不是環境）。

**根因**（已用 Node.js + 假 DOM 直接執行程式碼驗證確認）：

`buyable-ledger.html` 原始程式碼裡有一行用**執行期字串組合**產生 DOM id：

```js
var el = document.getElementById("tbl-" + r.id);
```

（`r.id` 的值是 `"longswing"` 或 `"value"`，來自 `HOLD_RULES` 陣列。）

合併腳本的 id 改名邏輯（`prefix_ids()` 函式）是用**正規表達式比對寫死的
字串樣式**（例如 `id="tbl-longswing"`、`getElementById("tbl-longswing")`）——
但上面這行是**動態串接**，原始碼裡根本沒有 `"tbl-longswing"` 這個完整字串
可以比對，所以沒有被改到，合併後這行還是在找舊的、沒加前綴的 `"tbl-longswing"`。

HTML 裡對應的元素已經被改名成 `id="buyable-tbl-longswing"`，所以
`document.getElementById("tbl-longswing")` 在瀏覽器裡會回傳 `null`，接下來
`el.innerHTML = ...` 對 `null` 賦值會直接丟出例外（TypeError），把**同一個
IIFE 裡後面所有還沒執行的程式碼全部中斷**——這就是為什麼不只 `tbl-longswing`/
`tbl-value` 是空的，連在它們後面才執行的 `rules-list`（規則手風琴）也一起
遭殃；而「總覽圖表」跟「附錄表格」因為程式碼寫在**這行動態組id之前/獨立
的另一個 IIFE**，才躲過一劫、正常顯示。

（PS：合併腳本裡其實已經有處理過一次「同類型」的動態 id 問題——`capital-ceiling.html`
跟 `case-reopened.html`、`reset-vs-continuous.html` 都有 `var uid = "r"+i;`
這種動態拼字串的寫法，組裝腳本已經有針對這幾行特別處理、加上前綴。這次
是漏抓了 `buyable-ledger.html` 特有的另一種動態拼字串寫法，兩者是同一類
問題，只是藏在不同檔案裡的不同寫法。）

## 3. 已經寫好、但還沒驗證的修法

在 `assemble_combined.py`（如果 scratchpad 還在，直接改那份；如果不在了，
下面重寫一份等價的腳本）的 `for i, (key, label, fname, has_root) in enumerate(TABS):`
迴圈裡，找到這一段（大約在抽取完 `logic` 之後）：

```python
    logic = extract_logic_script(html)
    logic = prefix_ids(logic, key)
    # prefix dynamic uid template strings to avoid cross-tab DOM id collisions
    logic = logic.replace('var uid = "r"+i;', f'var uid = "{key}-r"+i;')
    logic = logic.replace('var uid = "lv"+i;', f'var uid = "{key}-lv"+i;')
```

**已經加上這一行修法**（這一步已經做了，寫進了 scratchpad 裡的
`assemble_combined.py`，但因為使用者在這裡喊停，**還沒重新執行這支腳本、
沒有重新驗證、沒有重新發布**）：

```python
    logic = logic.replace('document.getElementById("tbl-" + r.id)',
                          f'document.getElementById("{key}-tbl-" + r.id)')
```
