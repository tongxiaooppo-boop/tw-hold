## 1. 使用者 Excel 估法與它的問題（已跟使用者講過）

原式：單月營收×3 × 毛利率 − 營業費用 + **最新季業外** → ×(1−稅率) → ×4 年化 → × 產業本益比 → 上檔空間%。
下半部「合理成長價」＝ 預估今年 EPS（上半年 ×2）× 交易所目前本益比（反推三個數字都對得上：4.48 × 41.7 = 186.8）。

- 1815 Q2 業外 4.08 億＝稅前 43%（近 8 季 −2.41～+4.08 億），被當成每季都有。
- 單月×3 受單月波動；產業本益比（上櫃電子零組件太雜）× 高峰 run-rate EPS → 樂觀算兩次。
- 實際「歸母淨利÷稅前」約 86%（表格填 20% 稅率）。

## 2. 計算（`app/valuation.py`，純函式 `estimate(qf, rev, px, per)` 回 dict）

| 項目 | 口徑（最終） |
|---|---|
| 營收 | 近 3 個**連續**月合計（缺月不湊）；並列 vs 最新財報季、YoY |
| 毛利率 | 最新一季 |
| 營業費用 | **最新季費用率 × 試算營收**（使用者拍板）；固定金額版 `inputs.run_fixed_opex` 只當對照 |
| 業外 | 主版本歸零（叫「排除業外」不叫核心，連利息費用也拿掉）；對照版加回近 4 季平均 |
| 稅 | 不估稅率：近 4 季「歸母淨利 ÷ 稅前」；<60% 或 >100% 警示 |
| 股數 | 近 4 季「淨利 ÷ EPS」中位數（|EPS|<0.05 跳過）；不用股本÷10 |
| 年化試算 EPS | 單季試算淨利 ÷ 股數 × 4 |
| 今年預估 EPS | 今年已公布季**實際** ＋ 未公布季 × 試算單季 EPS（`_year_block`）；去年 4 季齊才給年增 |
| 三段價 | **近 5 個日曆年各年平均本益比**（排除 per≤0；有效日 <20 的年不算；<3 年不給）的最低／中位數／最高 × 今年預估 EPS（使用者指定） |
| 區間太寬 | 最高年均 > 4×最低 → `pe["wide"]`，卡片不列三段價（展開照列） |
| 合理成長價 | 今年預估 EPS × `per` 最新一筆 >0 本益比（`_current_pe`，使用者 Excel 口徑） |
| 外資對照 | 全期日資料平均 ±1σ（PE band 口徑），只在展開列；註明外資用前瞻 PE、我們只有 trailing |
| 循環提醒 | 最新季營益率贏過近 24 季 ≥80% → info |

不試算（`ok=False`）：財報 <4 季、最新季無毛利／營業利益／稅前（金融業）、月營收不足 3 個連續月。
設計經 gpt-6.1-sol 審一輪（改名排除業外、拿掉稅率硬夾／20% 補值／股本÷10、敏感度矩陣取代三情境、各資料標日期）。
